Interface Contract (v1.0)
Tanggal Disepakati: 10 November 2026

Dokumen ini adalah kesepakatan teknis antara Analysis Layer dan Infrastructure & Operations Layer untuk memastikan kode analisis dapat berjalan lancar di lingkungan cloud yang disiapkan.

 1. Kebutuhan Data & Input
 Format Data: CSV
 Sumber Data: Brazilian E-Commerce Public Dataset by Olist https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
 Ukuran Data: (Menunggu konfirmasi lebih lanjut untuk penyesuaian memori/RAM)
 2. Kebutuhan Runtime & Lingkungan (Environment)
 Bahasa Pemrograman: Python
 Library/Dependencies Tambahan: (Tim analisis nanti akan melampirkan file `requirements.txt` berisi daftar library seperti pandas, matplotlib, dll)
 3. Output Akhir & Akses
 Bentuk Output: Web Dashboard interaktif
 Framework Dashboard: Streamlit
 Aksesibilitas: Tim infrastruktur akan memastikan Streamlit dapat diakses melalui browser menggunakan IP/URL publik dari layanan cloud.

Riwayat Revisi:
 v1.0 - Penetapan teknologi awal (Python, CSV, Streamlit).
